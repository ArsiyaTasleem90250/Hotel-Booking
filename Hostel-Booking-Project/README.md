# Hostel Booking Project

A beginner-friendly frontend project for a Git practical.

## Features
- Displays three hostel options and monthly fees.
- Select a hostel using the Book Room button.
- Collects student name and a 10-digit phone number.
- Shows a booking confirmation message (demo only; no database or payment).

## Run
Open `index.html` in a browser. No installation is required.

## Suggested Git practical
Use this project to practice:
- `main` and `develop` branches
- feature branches
- commits and pushes
- merging and resolving a conflict in `README.md` or `index.html`

This is a frontend demonstration project. It does not store bookings permanently.
